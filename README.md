# WoG 助手下載

此儲存庫提供 WoG 助手的版本說明、加密完整安裝包及 SHA-256 驗證檔。

[前往最新版本](https://github.com/karustestjp001-dotcom/WoGAssistant-Releases/releases/latest)

## 使用方式

- 下載 Release 中的加密 RAR 完整包，使用另行取得的密碼解壓。
- 請完整解壓，不要只複製 EXE。依包內「開始使用.txt」及「安裝與解除安裝說明.md」操作。
- 已包含助手與遊戲連接所需的相依套件；Steam 與遊戲本體需自行安裝。
- 提供自訂條件合成、祭壇領鑽石與定時自動化。
- 需要關閉遊戲與助手後，再執行包內解除安裝程序。

## 相容性

目前版本 v0.4.1 已驗證 WoG 1.0.1 / Steam build 25224970 / Unity 6000.0.59。
遊戲更新可能需要對應新版助手；此版本尚未提供完整的更新後相容性自動驗證。

解壓密碼由持有人另行提供，不會公布在儲存庫、版本說明或附件內。
第三方套件的授權與來源資訊包含於完整包內。
