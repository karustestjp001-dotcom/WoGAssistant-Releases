# WoG 助手下載

此公開儲存庫提供版本說明、加密的 Windows 完整安裝包及 SHA-256 驗證檔。開發專案原始碼不在此儲存庫公開。

[下載最新版本](https://github.com/karustestjp001-dotcom/WoGAssistant-Releases/releases/latest)

## 安裝與更新

1. 在最新 Release 的 Assets 下載 `WoGAssistant-v0.8.16-portable-encrypted.rar`。
2. 使用支援 RAR5 加密的解壓縮工具，輸入另行取得的密碼，完整解壓到固定資料夾；不要只複製 EXE。
3. 關閉 WoG 遊戲與舊助手，執行「安裝WoG助手.cmd」。
4. 從 Steam 啟動遊戲並登入，再開啟 `WoGAssistant.exe`。
5. 首次使用到「Discord／月卡」登入及申請；管理員核准後開通 30 天。WoG 資格獨立計算。
6. 往後到「關於／更新」按「檢查更新」，查看版本與說明，再開啟下載頁更新。

更新保留原有遊戲設定與同一台電腦的 Discord 登入。跨電腦需重新登入。解除安裝請使用包內「解除安裝WoG助手.cmd」，詳細步驟見「安裝與解除安裝說明.md」。

## 功能

- 定時自動化與獨立的懶人模式（Beta）。
- 合成、祭壇鑽石、郵件及免費門票領取。
- 訓練目標、戰場清票、遺物升級、倉庫整理與自動換裝。
- 遊戲前景熱鍵呼叫、隱藏到通知區、問題報告匯出。
- 手動檢查 GitHub 新版及閱讀更新說明。

## 使用需求

Windows 10／11 x64，需自行安裝 Steam 與 WoG。助手包含必要的 .NET 與遊戲連接相依元件。遊戲更新後可能需要對應新版助手。

此版更新功能會開啟下載頁，由使用者下載及安裝完整包。檢查更新、查看狀態及匯出問題報告不要求有效月卡。
